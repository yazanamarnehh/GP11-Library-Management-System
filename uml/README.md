# UML and architecture diagrams

Editable sources only (`.puml`, `.mmd`, `.drawio`); exported PNG/SVG go in `rendered/` with the same
base name. Suggested names:

| File | Diagram |
|---|---|
| `c4-context.puml` | C4 Level 1 — System Context |
| `c4-container.puml` | C4 Level 2 — Containers |
| `component.puml` | Component view |
| `use-case.puml` | Use case diagram |
| `seq-<use-case>.puml` | Sequence diagram per important use case |
| `class-domain.puml` | Domain class diagram |
| `erd.puml` | Data model / ERD |
| `state-<entity>.puml` | State diagram (e.g. copy, loan, reservation) |
| `activity-<workflow>.puml` | Activity diagram with swimlanes |
| `deployment.puml` | Deployment view |
