## Goal

Model how each actor interacts with the Library Management System: a use case diagram for the whole
system, fully dressed descriptions of the important use cases, and two sequence diagrams for the
catalog increment (v0.1.0).

## Requirements and design references

- Requirements: FR-01 – FR-34 (coverage), in detail FR-01–FR-06, FR-13, FR-14, FR-17, FR-21, FR-22,
  FR-29; NFR-01, NFR-02, NFR-03, NFR-06, NFR-09; BR-01 – BR-09
- Task brief: [docs/process/v0.1.0-design-tasks.md — Task C](../docs/process/v0.1.0-design-tasks.md)
- Glossary: [docs/project_description.md §6](../docs/project_description.md)
- Use case names: *Use Case* column of [docs/traceability_matrix.md](../docs/traceability_matrix.md)
- Architecture (Task B): `uml/component.puml` — `CatalogController`, `CatalogService`

## Key instructions to the agent

1. "Do Task C from `docs/process/v0.1.0-design-tasks.md`." Read the requirements, glossary,
   traceability matrix and the Task B component diagram first so all names match.
2. Draw `uml/use-case.puml` for the whole system with actors Guest, Member, Librarian,
   Administrator and Scheduler; one use case per FR group, named as in the traceability matrix;
   generalisation Guest ← Member; «include» for steps that always happen (Verify member eligibility),
   «extend» with a condition for steps that happen only sometimes.
3. Show the FR IDs inside each use case so the diagram traces to the requirements.
4. Write `docs/use_cases.md` with fully dressed descriptions of Search catalog, Manage titles,
   Manage copies, Check out copy, Return copy, Renew loan, Reserve title and Record fine payment
   (ID, actors, FR/BR, preconditions, numbered main scenario, alternative/exception flows,
   postconditions), and a coverage table proving every FR-01–FR-34 maps to a use case.
5. Draw `uml/seq-catalog-search.puml` (Guest → CatalogController → CatalogService → TitleRepository →
   PostgreSQL, returning available-copy counts) and `uml/seq-catalog-add-copy.puml` (Librarian adds a
   copy, including the duplicate-barcode exception path).
6. Render every diagram to `uml/rendered/` and check that it renders without errors.
